One original funny line, capped at 200 characters, that lands its laugh on first read — a dog that took fetch lessons far too seriously. The program writes the line deterministically to `/output/entry.txt` for make.fun's "One Line, One Laugh" bounty.

The line is 124 characters, well under the competition's 200-character gate, and the program is fully deterministic: it runs twice and produces byte-identical output, using only the Node 22 standard library and no network access.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`. To write it somewhere else instead, pass an output directory: `node main.ts ./output`.
